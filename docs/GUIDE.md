# SnapLingo 使用手册

> 面向第一次使用的人。照着「30 秒上手」做一次就能用；配置看不懂时，回头看「4. 逐项解释」。
> 程序界面本身没有主窗口，全部在**系统托盘**里。

---

## 1. 30 秒上手

1. **启动**：双击 SnapLingo（首次启动会自己弹出「设置」窗口，因为还没配好）。
2. **选两件事**（设置里左右两页）：
   - 「识别」页 → 识别引擎：先选 **Windows 内置 OCR**（不用注册、不用联网、开箱即用）。
   - 「翻译」页 → 翻译渠道：想省事先选 **仅识别不翻译**，能用了再回来加翻译。
3. **开始用**：按 `Ctrl + Alt + Z`（或右键托盘图标 →「截图翻译」）→ 拖拽框选一段文字 → 松开鼠标 → 结果窗口出现。

结果窗口里：

| 按钮 | 作用 |
| --- | --- |
| 原文 / 译文 / 对照 | 切换只看原文、只看译文，或上下对照 |
| 重试 | 上一次识别或翻译失败时，用同一张截图重跑（不用重新框选） |
| 复制 | 复制当前视图的文字（看原文就复制原文） |
| 截图 | 显示或收起截图图片（图片在译文上方，点一下可放大） |
| ✕ / Esc | 关闭结果窗口（不会退出程序） |

> 程序常驻托盘，关闭窗口只是隐藏。真正退出：右键托盘图标 →「退出 SnapLingo」。

> 窗口位置与大小：**首次弹出在当前屏幕正中、大小约为屏幕的一半**（放不下时内容会滚动）；之后每次弹出都会在本次运行内**沿用你上次拖出来的尺寸**，并仍居中显示——程序不会自动改回去。可以像普通窗口一样拖拽边缘调整。如果你更希望窗口高度跟着译文长短变化，打开 **设置 → 外观 →「结果窗口自适应内容」**（开启后也不会超过屏幕高度）。

## 2. 三种推荐配置

| 你的目标 | 识别引擎 | 翻译渠道 | 需要准备 |
| --- | --- | --- | --- |
| **完全离线**（公司内网、隐私优先） | Windows 内置 OCR，或本地 OCR 服务 | 仅识别不翻译 | 无（用本地 OCR 服务需先装 Umi-OCR） |
| **最省事的在线翻译**（推荐） | Windows 内置 OCR | OpenAI 兼容（如 NVIDIA NIM / 智谱） | 一个接口地址 + API Key |
| **一条请求搞定**（准确率最高） | 由翻译渠道完成（有道的图片翻译） | 有道智云 / 百度翻译 / 腾讯云翻译 | 该渠道要**单独开通「图片翻译」** |
| **最准的图文混排** | 视觉大模型 | 大模型（同一家或另一家） | 多模态模型 + Key |

第一次配翻译，推荐顺序：**Windows 内置 OCR + OpenAI 兼容接口**（两者互不依赖，任一处出问题都能单独排查）。

## 3. 界面速查

- **托盘左键单击** = 打开设置窗口；**右键** = 菜单（截图翻译 / 取消本次截图 / 历史记录 / 查看日志 / 设置 / 开机自启动 / 退出）。
- **快捷键**默认 `Ctrl + Alt + Z`，可改（设置 → 通用）。截图过程中再按一次 = 取消。
- 框选时：**Esc 或右键**取消；**松开鼠标**即开始识别；选区小于 4px 会被当作取消。
- 结果窗口：**Esc** 关闭；**失焦自动隐藏**可在设置里开。

## 4. 逐项解释

### 4.1 通用

| 项目 | 说明 |
| --- | --- |
| 全局快捷键 | 在任何程序里按下都能开始截图。点输入框后直接按新组合键即可更换；被别的软件占用时保存会失败并回滚。 |
| 开机自启动 | 登录后自动常驻托盘。 |
| 截图模式 | 「全部显示器」= 每个屏幕都能框选（多屏推荐）；「只截鼠标所在显示器」= 只冻结鼠标那个屏幕，切换更快。 |

### 4.2 识别（OCR）

四种引擎的区别：

| 引擎 | 联网 | 需要 Key | 速度 | 适合 |
| --- | --- | --- | --- | --- |
| Windows 内置 OCR | 否 | 否 | 很快 | 印刷体、屏幕截图正文（默认） |
| 本地 OCR 服务 | 否（只连本机） | 否 | 快 | 中文/艺术字/竖排更好，见 4.2.3 |
| 视觉大模型 | 是 | 是 | 中等 | 图文混排、手写、复杂排版、表格 |
| 由翻译渠道完成 | 是 | 是 | 快 | 想省一次调用：图片直接给云端「识别+翻译」 |

**4.2.1 Windows 内置 OCR**：无需配置。若提示缺少语言包：Windows 设置 → 时间和语言 → 语言和区域 → 添加语言 → 语言选项 → 勾选「光学字符识别」。语言留「自动」即可。

**4.2.2 视觉大模型**：填 OpenAI 兼容的 **接口地址**（要带 `/v1`）、**API Key**、**模型名**。可点「预设」下拉直接选常用服务商（NVIDIA NIM、智谱、OpenCode Zen、Gemini…），会自动填好地址与模型；**每个厂商的地址 / 模型 / 密钥分开保存**，切换厂商会一起切换，不会串用。「一次调用」开启后，同一次请求同时返回原文和译文（省一次翻译调用，但提示词更复杂，个别模型会偷懒）。

**4.2.3 本地 OCR 服务（Umi-OCR，免费开源，图片不出本机）**：
1. 下载解压 Umi-OCR（设置页「下载 Umi-OCR」按钮有链接），双击运行；
2. 在 Umi-OCR 的「全局设置 → 常规」里确认 **HTTP 服务已开启**，端口默认 `1224`；
3. 回到 SnapLingo：识别引擎选「本地 OCR 服务」，地址填 `http://127.0.0.1:1224`，点「检测服务」→ 显示可用即可。

> 只想离线时：识别选它 + 翻译选「仅识别不翻译」，全程不联网。

### 4.3 翻译

8 个渠道各自要填什么、去哪申请：

| 渠道 | 需要填 | 申请地址 |
| --- | --- | --- |
| OpenAI 兼容 | 接口地址 + Key + 模型 | 视服务商而定（点「预设」有常见服务商） |
| DeepL | Key（选 Free / Pro） | https://www.deepl.com/pro-api |
| 微软翻译 | Key + 区域 | https://portal.azure.com → 翻译服务 |
| 谷歌翻译 | Key | https://console.cloud.google.com → 翻译 API |
| 有道智云 | 应用 ID + 应用密钥 | https://ai.youdao.com |
| 百度翻译 | AppID + 密钥 | https://fanyi-api.baidu.com |
| 腾讯云翻译 | SecretId + SecretKey + 区域 | https://console.cloud.tencent.com/tmt |
| 仅识别不翻译 | — | — |

- **每个渠道的 Key 各存各的**，切换渠道不会把别家的密钥带过来。
- **测试连接**按钮：点一下就知道地址/密钥/模型有没有问题。
- 卡片下方的「**实际调用**」一行会显示这次真正要请求的方法 + 地址（含档位影响的参数），方便和官方文档对照。
- **目标语言**：`zh-CN`（简体）、`zh-TW`（繁体）、`en` 等；云端渠道支持的范围以各家文档为准。也可以选 **`auto`（智能判断）**：识别出的原文主要是中文就译成英文，否则译成中文——中译英、英译中来回切换不用改设置。结果窗口底部的「目标语言」下拉可以随手改，改完立即重新翻译并记住这个选择。
- **档位**（有道 / 百度 / 腾讯）：
  - 百度：**通用文本翻译** 与 **大模型翻译** 是**两个接口**（开通要求也不同），切换后地址会变；
  - 有道 / 腾讯：档位是**同一个地址上的一个参数**（有道 `translateOption`、腾讯 `Mode`），只影响「一步图片翻译」。
- **自定义提示词**：留空即可；想调整语气或术语时再改。

### 4.4 截图

| 项目 | 建议 |
| --- | --- |
| 小图自动放大 | 保持开启（小字号截图识别率明显更高） |
| 长边上限 | 默认 1568。文字很大很糊时可升到 2000+，但请求更慢更贵 |
| JPEG 质量 | 默认 88。云端 OCR 偶尔看不清时可升到 95 |

### 4.5 外观

主题（跟随系统 / 亮 / 暗 / 纸张 / 午夜 / 森林 / 高对比）、界面语言（中文 / English）、结果窗口字号、是否显示截图、出结果是否自动复制译文、结果窗口失焦时是否自动隐藏、失败时是否弹出右下角提示卡片、结果窗口高度是否随内容自适应。

### 4.6 历史 / 日志

- **历史**：保存最近若干次原文与译文（可关闭、可清空、单条删除），刷新后仍在。
- **日志**：每次执行都会记录**走了哪个引擎、请求哪个地址、参数与失败原因**。支持按类型（ERROR / WARN / INFO / DEBUG）筛选、关键字过滤、复制、清空、打开文件位置。排查问题时把最近一次执行的几行发出来即可。
  - 日志默认最新在最上面。
  - 地址里带 `key/token/sign` 之类的查询参数会被替换成 `***`，不会泄露密钥。

### 4.7 关于

配置目录、日志文件位置、快捷键一览、显示器列表，以及「使用手册」（就是本文件）入口。

## 5. 出错了怎么办

| 现象 / 报错 | 原因与处理 |
| --- | --- |
| 提示还没有可用的 OCR | 识别引擎没配好：换「Windows 内置 OCR」，或给视觉大模型填好地址/Key/模型。 |
| 提示缺少 OCR 语言包 | 按 4.2.1 添加系统语言功能；或改用本地 OCR 服务 / 视觉大模型。 |
| 401 / 403 鉴权失败 | 地址或 Key 不对；地址要带 `/v1`；403 也可能是「该模型在你所在地区不可用」，换个模型。 |
| 429 频率受限 | 等一会儿，或换更轻量的模型（程序会自动重试 3 次）。 |
| 503 服务端过载 | 上游免费额度/负载问题，稍后重试或换模型。 |
| 百度 `52003 未授权用户` | 该 AppID 没开通「图片翻译」服务（要单独申请）；或在识别页换回 Windows 内置 OCR。程序会自动回退到本机识别。 |
| 百度 `69005/69006/69007` | 图片超过 4MB / 尺寸不合 / 格式不支持。框小一点，或换识别引擎。 |
| 有道 `errorCode` 非 0 | 按提示的说明处理；常见是密钥错或不支持的语言方向。 |
| 本地 OCR 服务连不上 | 服务没启动 / HTTP 服务没开 / 端口不一致 / 地址缺 `http://`；点「检测服务」验证。 |
| 翻译特别慢或超时 | 单请求超时 60 秒、最多重试 3 次；整体任务 150 秒会中止并提示重试。长文本会自动分块。 |
| 按快捷键没反应 | 被其它软件占用 → 设置 → 通用 → 重新录制；保存失败会自动回滚并提示。 |
| 程序好像卡住了 / 选区窗口关不掉 | ① 再按一次快捷键或托盘「取消本次截图」；② 什么都不做，3 分钟后选区自动取消；③ 主线程真的无响应时，程序会在 4 分钟后自动退出，重启即可。 |
| 窗口里有「原先的截图」 | 那是上一次的缓存（用于「重试」），重新截图后会被替换。 |
| 右下角出现一张 SnapLingo 的提示卡片 | 这是程序自己的通知（**不是** Windows 系统通知）：说明某次执行失败了，点击卡片可直接跳到日志页，不点也会在几秒后自动消失。不想要这张卡片可以在设置 → 外观里关掉（关掉后失败只出现在结果窗口和日志里）。 |

## 6. 隐私与安全

- 截图**只在内存**里处理，不写入磁盘（除非你自己点了「复制」）。
- 用 **Windows 内置 OCR / 本地 OCR 服务**时，图片完全不出本机；用**云端识别（视觉大模型 / 图片翻译）**时，图片会发给你配置的那家服务商。
- **API Key 以明文保存在** `%APPDATA%\SnapLingo\config.json`（受 Windows 用户目录权限保护）。介意的话建议用**只有翻译权限的独立 Key**，随时可在服务商控制台吊销。
- 日志里的地址与参数会脱敏，不写完整密钥，请求失败时打印的错误信息也会去掉地址里的密钥（`key/token/sign` 一律替换成 `***`）；但接口返回的响应体仍按原文记录，方便排查签名 / 配额问题，贴日志前请自己过一眼。

## 7. 开发者

```bash
npm install
npm run tauri dev      # 开发（需要先有 Rust + MSVC 工具链）
npm run tauri build    # 打包，产物在 src-tauri/target/release/bundle/nsis/
```

技术链路：全局快捷键 → 冻结屏幕（xcap）→ 无边框置顶覆盖层框选 → Rust 侧裁剪/预处理 → OCR（Windows.Media.Ocr / 本地 HTTP / 视觉大模型 / 云端图片翻译）→ 翻译（OpenAI 兼容 / DeepL / 微软 / 谷歌 / 有道 / 百度 / 腾讯）→ 结果窗口。

更细的实现说明与项目结构见仓库根目录 `README.md`。
